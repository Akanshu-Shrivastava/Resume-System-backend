### 🧩 **Module Overview**
This backend module provides secure and scalable APIs for managing user authentication and resume data.  
It includes:
- **User Registration & Login** with JWT-based authentication  
- **Resume CRUD APIs** for managing personal info, skills, education, and experience  
- **Auto Summary Generation Endpoint** (AI/automation-ready placeholder)  
- **Proper Folder Structure & Mongoose Models** for clean and maintainable code  

---

### 🛠️ **Tools & Libraries Used**
- **Node.js & Express.js** – Server and routing  
- **MongoDB & Mongoose** – Database and schema modeling  
- **JWT (jsonwebtoken)** – Authentication mechanism  
- **bcrypt.js** – Secure password hashing  
- **dotenv** – Environment configuration  
- **Nodemon** – Development auto-restart utility

### 🚀 **How This Module Contributes**
This backend can be easily integrated with the frontend or other sub-platforms (internship, hackathon, and course modules).  
It provides a foundation for:
- Centralized user profiles  
- Real-time resume updates  
- Verified data integration via API
